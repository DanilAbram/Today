# Today

A calm daily planner: tasks, habits and a focus timer on one page.

- **Tasks** for today and tomorrow, with drag to reorder and carry-over of unfinished ones
- **Habits** with streaks, chosen weekdays, skip days and a strength score
- **Focus timer** with any length from 1 to 180 minutes
- **Calendar** with your streak and a weekly review
- **7 languages:** English, Русский, Español, Français, Deutsch, Português, Українська
- **Comfort settings:** text size, high contrast, less motion
- Works offline, can be installed as an app, and keeps all data in your browser

Plain HTML, CSS and JavaScript. No build step and no dependencies.

## Run it

```bash
node .claude/serve.js
```

Then open http://localhost:5180.

## Run the tests

```bash
node --test tests/
```
